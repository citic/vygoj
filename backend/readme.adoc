= Vygoj backend

The Vygoj backend is a Code Execution Service because provides a web service to allow web applications to run source code into a sandboxed environment. It supports tests for concurrent and distributed programming.

== Installation

The backend is developed in Python and requires Flask. A `Makefile` is provided to ease this process. The default rule creates a Python virtual environment, installs dependencies, and run the backend for debugging.

[source,bash]
----
$ make
----

You can remove the virtual environment

[source,bash]
----
$ make clean
----
