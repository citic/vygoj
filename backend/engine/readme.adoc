= Vygoj Code Execution Engine

The Code Execution Engine is a backend module that executes code into a sandboxed environment using Docker containers. It supports the concurrent programming paradigm. That is, it allows the creation of execution threads and provides statistics to the frontend about the concurrent resources used. Distributed programming may be provided in the future.


[[setup]]
== Set up

The Vygoj Code Execution Engine is developed in Python and requires Docker. A `Makefile` is provided to ease the installation and run on Debian-based distributions. If you do not have Docker installed, the following command installs an older version from Debian repositories using `apt`:

[source,sh]
----
sudo make install
----

For macOS `make install` (without sudo) installs the official Docker Desktop and client. It assumes you have Homebrew installed. Run Docker manually after installing to accept the license and configure the service. Alternatively, for Debian you may install the latest Docker version from Docker's official repositories using:

[source,sh]
----
sudo make official-install
----

VygOJ Code Execution Engine requires a Debian-based Docker's image called `vygoj-engine`. This image has common tools for development in the programming languages supported by VygOJ. The recipe to create this image are in the link:Dockerfile[Dockerfile]. To build the image run:

[source,sh]
----
make image
----

The image is based on a fixed release of Debian (`debian:trixie`), whose packages receive security updates. Rebuild the image regularly to get them:

[source,sh]
----
make rebuild
----

It downloads the last version of the base image and installs the packages again. The name `vygoj-engine` moves to the new image when it is built, so the running solutions end in the old image and the new ones use the new image, without stopping the backend. Then it removes the old images of VygOJ that no container uses (the ones with the `vygoj` label of the `Dockerfile`). The rules of the images are shared with the language server in `common/docker.mk`, and `make rebuild` in the root folder rebuilds both.


[[run]]
== Interactive run

You can create a container from the `vygoj-engine` image an run commands interactively with:

[source,sh]
----
make run
----

The `make run` is the default rule, therefore you may just type `make`.


[[clean]]
== Cleaning

The following command stops and removes all containers of the image and finally removes the image (`make remove-image` does the same). Please be sure the VygOJ backend is stopped in order to avoid data corruption and affecting real users.

[source,sh]
----
make clean
----
