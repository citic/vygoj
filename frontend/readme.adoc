The web application component allows professors to create courses and students to attend them. It is compound of two parts:

. The app's frontend is an XHTML/CSS/JS application for running on web browsers.
. The app's backend is a Python application using Flask framework.

You need command-line access to the machine where the app will be installed. The following instructions assume a Unix-like environment.
