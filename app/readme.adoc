= Vygoj web application
:toc:

The web application component allows professors to create courses and students to follow them. It is compound of two parts:

. The frontend is an XHTML/CSS/JS application for running on web browsers.
. The backend is a Node.js application using Express framework and written in TypeScript.

Therefore you need command-line access to the machine where the app will be installed. The following instructions assume a Unix-like enviroment.




== Install and run

Clone this repository in the machine where the app will run. The commands in this document suppose you are in the `app/` folder:

[source,sh]
----
git clone https://git.ucr.ac.cr/ecci/vygoj.git
cd vygoj/app
----

=== Configure

Before running Vygoj web application for first time, it must be configured. Copy the example configuration file. The `-n` option avoids overwriting the file if you already have a configuration.

[source,sh]
----
cp -n config/config-example.json config/config.json
----

Then, edit the `config/config.json` using your favorite text editor. Change the network port you expect the web application is listening for connections. By default 8080 is used.

If you do not have a database, you may want to create one link:https://docs.mongodb.com/manual/administration/install-community/[locally^] or link:https://docs.atlas.mongodb.com/getting-started/[in the cloud]. Then, provide a MongoDB database connection string in your config file. If your database is local prefer `0.0.0.0` instead of `localhost` in your connection string, e.g:

[source,js]
----
"database": "mongodb://vygoj-app:AGoodPass@0.0.0.0:27017/vygoj?authSource=admin"
----

Create a user for the Vygoj Web Application. You can use any MongoDB client, such as `mongosh`:

[source,js]
----
db.createUser({user: 'vygoj-app', pwd: 'AGoodPass', roles: [{role: 'readWrite', db: 'vygoj'}]})
----

If your database is in the cloud, e.g with MongoDB Atlas, in Database Access menu create a `vygoj-app` user with read-and-write permissions, generate a password and save it. In the Network Access menu, add the IP of the machine where the App will be running. Finally, go to the database list, press Connect, then "Connect an application", and copy the database connection string that starts with `mongodb+srv:`. Paste it in the `database` field of your `config/config.json` file and replace the <password> by the actual generated password.

If your database is empty, you need to create an administrator user. The following command will create an admin user with default values and password:

[source,sh]
----
node dist/util/createUser.js
----

You can provide optional command line arguments to set the user full name, password, email, and other properties. Use `node dist/util/createUser.js help` to get them.




=== Run the server

To run the server temporally:

[source,sh]
----
npm start
----

To run the server and keep it running after crashes or reboots (it requires pm2):

[source,sh]
----
npm run server
----

To restart the server after changes made to the source code

[source,sh]
----
npm run restart
----





== Development

For setting a development environment, consider the following toolchain. link:https://code.visualstudio.com/[Visual Studio Code^] is suggested as IDE.

The TypeScript monitor `tsc-watch` can detect any change in `.ts` files, incrementally compile them, and restart the server. For Linux you may want to install `tsc-watch` with `sudo` privileges (also `eslint` and `stylelint`).

[source,sh]
----
npm i -g tsc-watch
npm run dev
----

Your IDE may detect the linters configuration files included in the project's files. For TypeScript linting, link:https://eslint.org/[ESLint^] is used with the AirBnb settings. If you want to run it on the command line:

[source,sh]
----
npm i -g eslint
npm run lint
----

For CSS code the link:https://stylelint.io/[Stylelint^] tool is used. 

[source,sh]
----
npm i -g stylelint
npm run stylelint
----



== Database

You may want to create a local database for development in order to avoid interfering your production environment. MongoDB is used as database management system. You can follow the link:https://www.mongodb.com/docs/manual/administration/install-community/[official instructions^] to locally install MongoDB. Then, create a connection URL for a new database:

[source,sh]
----
$ mongosh

> use <database_name>
> db.createUser({
  user: "<username>",
  pwd: "<password>",
  roles: [ "dbOwner" ]
});
> exit
$
----

Your connection URL will be:

[source,js]
----
"mongodb://<username>:<password>@0.0.0.0:27017/<database_name>"
----

Copy the `config/config-example.json` file to `config/config.json` and set the URL for the `"database"` field.

Create the VygOJ admin user by running the following command:

[source,sh]
----
$ node dist/util/createUser.js
----

Now you can visit the VygOJ app website, by default on link:http://localhost:8080[http://localhost:8080^] by using a web browser. Login using the VygOJ admin credentials, and create professor users. They can create their own courses and invite their students.




=== Directory structure

JavaScript files that start with uppercase, e.g `Course.js`, export a class. Camel-case files that start with lowercase, e.g `courseController.js` export a symbol, usually a singleton object.

. link:src/common/[common] contains common code used by front and backend

. link:src/public/[public] contains static XHTML, CSS, JS, images, sound, video files that are sent to clients with no changes.

. link:src/views/[views] contains XHTML templates using linkg:https://eta.js.org/[eta^] engine.

. link:src/routes/[routes] routes the HTTP requests to the respective controller looking into the HTTP method and URI parts.

. link:src/controllers/[controllers] contains singleton objects for controlling the big parts of the judge, such as users, courses, questions, and problems. They manage the model objets for fetching the data, filling out the templates, and respond to clients.

. link:src/models/[models] contains classes for managing the domain data (persistence) and logic of users, courses, questions, problems, and so on.

. link:src/util/[util] contains classes for miscelaneous tasks, such as configuration and database management.
