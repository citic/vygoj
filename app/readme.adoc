= Vygoj web application
:toc:

The web application component allows professors to create courses and students to follow them. It is compound of two parts:

. The frontend is an XHTML/CSS/JS application for running on web browsers.
. The backend is a Node.js application using Express framework and written in TypeScript.

Therefore you need command-line access to the machine where the app will be installed. The following instructions assume a Unix-like enviroment.




== Install and run

Clone this repository in the machine where the app will run. The commands in this document suppose you are in the `app/` folder:

[source,sh]
----
git clone https://git.ucr.ac.cr/ecci/vygoj.git
cd vygoj/app
----

=== Configure

Before running Vygoj web application for first time, it must be configured. Copy the example configuration file. The `-n` option avoids overwriting the file if you already have a configuration.

[source,sh]
----
cp -n config/config-example.json config/config.json
----

Then, edit the `config/config.json` using your favorite text editor. Change the network port you expect the web application is listening for connections. By default 8080 is used.

Provide a MongoDB database connection string. If you do not have a database, you may want to create one link:https://docs.mongodb.com/manual/administration/install-community/[locally^] or link:https://docs.atlas.mongodb.com/getting-started/[in the cloud].

If your database is local, create a user for the Vygoj Web Application. You can use any MongoDB client, such as `mongosh`. The following code include the respective database connection string as a comment:

[source,js]
----
db.createUser({user: 'vygoj-app', pwd: 'AGoodPass', roles: [{role: 'readWrite', db: 'vygoj'}]})
// "database": "mongodb://vygoj-app:AGoodPass@localhost:27017/vygoj?authSource=admin"
----

If your database is in the cloud, e.g with MongoDB Atlas, in Database Access menu create a `vygoj-app` user with read-and-write permissions, generate a password and save it. In the Network Access menu, add the IP of the machine where the App will be running. Finally, go to the database list, press Connect, then "Connect an application", and copy the database connection string that starts with `mongodb+srv:`. Paste it in the `database` field of your `config/config.json` file and replace the <password> by the actual generated password.

If your database is empty, you need to create an administrator user. The following command will create an admin user with default values and password:

[source,sh]
----
node dist/util/createUser.js
----

You can provide optional command line arguments to set the user full name, password, email, and other properties. Use `node dist/util/createUser.js help` to get them.




=== Run the server

To run the server temporally:

[source,sh]
----
npm start
----

To run the server and keep it running after crashes or reboots (it requires pm2):

[source,sh]
----
npm run server
----

To restart the server after changes made to the source code

[source,sh]
----
npm run restart
----





== Development

For setting a development environment, consider the following toolchain. link:https://code.visualstudio.com/[Visual Studio Code^] is suggested as the preferred IDE.

The TypeScript monitor `tsc-watch` can detect any change in `.ts` files, incrementally compile them, and restart the server:

[source,sh]
----
sudo npm i -g tsc-watch
npm run dev
----

Your IDE may detect the linters configuration files included in the project's files. For TypeScript linting, link:https://eslint.org/[ESLint^] is used with the AirBnb settings. If you want to run it on the command line:

[source,sh]
----
sudo npm i -g eslint
npm run lint
----

For CSS code the link:https://stylelint.io/[Stylelint^] tool is used. 

[source,sh]
----
sudo npm i -g stylelint
npm run stylelint
----






=== Directory structure

JavaScript files that start with uppercase, e.g `Course.js`, export a class. Camel-case files that start with lowercase, e.g `courseController.js` export a symbol, usually a singleton object.

. link:common/[] contains common code used by front and backend

. link:public/[] contains static XHTML, CSS, JS, images, sound, video files that are sent to clients with no changes.

. link:views/[] contains XHTML templates using linkg:https://eta.js.org/[eta^] engine.

. link:routes/[] routes the HTTP requests to the respective controller looking into the HTTP method and URI parts.

. link:controllers/[] contains singleton objects for controlling the big parts of the judge, such as users, courses, questions, and problems. They manage the model objets for fetching the data, filling out the templates, and respond to clients.

. link:models/[] contains classes for managing the domain data (persistence) and logic of users, courses, questions, problems, and so on.

. link:util/[] contains classes for miscelaneous tasks, such as configuration and database management.
